Dataset & model information

Active disease model: PlantVillage (trained model included in this deployment).

  • Training images: 54,305 labelled images
  • Disease classes: 38 crop/disease classes
  • Crop species: 14 in the active PlantVillage model
  • Held-out test images: 10,709
  • Reported test accuracy: 76.9%
  • Macro-F1: 71.8%

Planned expansion dataset: FC45DHLPD (15 crops / 45 disease categories). Its downloader and preparation scripts are in the repository, but the full dataset has not yet been downloaded and used to train the live model. It is not active yet.

Only crops with matching classes in the active model can be diagnosed. A crop appearing in a general crop list does not mean the disease model supports it. Never use another crop's prediction as a diagnosis.
